# 🛡️ SecurePass - Passwordless Biometric Authentication

## 📌 Project Overview

SecurePass is a Passwordless Biometric Authentication System developed as a Final Year B.Tech Computer Science Engineering project.

The system allows users to authenticate using biometric methods instead of traditional passwords.

## 🚀 Features

- 🎤 Voice Registration
- 🎤 Voice Login
- 😀 Face Registration
- 😀 Face Login
- 📊 Admin Dashboard
- 👥 User Management
- 📄 PDF Report Generation
- 📊 Excel Report Generation
- 📜 Login History
- 🔒 Passwordless Authentication
- 💾 SQLite Database

## ⚙ Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/Passwordless-Biometric-Auth.git
```

### Open Project

```bash
cd Passwordless-Biometric-Auth
```

### Install Requirements

```bash
pip install -r requirements.txt
```

### Run Flask

```bash
python app.py
```

### Open Frontend

Run **index.html** using Live Server.
